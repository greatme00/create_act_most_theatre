# Журнал актёра — V2

Это отдельная, улучшенная версия. Она не меняет старую папку `git_acts` и не
использует её базу. В V2: чистый русский текст, кнопочный календарь, отмена
действия, автоматические цены, просмотр итогов за месяц, удаление ошибочных
записей и создание акта Word.

Название роли не спрашивается. Время спектакля бот спросит только если такое же
название уже добавлено на ту же дату. Дата, время начала и окончания репетиции
выбираются кнопками: календарь, затем час и минуты с шагом 15 минут.

Репетиция до 3 часов включительно считается одной. Дольше 3 часов — двумя,
дольше 9 часов — тремя. Если время не указывать, считается одна репетиция.

## Напоминания

Бот в 10:00 по Москве отправляет каждому пользователю напоминание о его
репетициях и спектаклях на следующий календарный день. Чтобы это работало,
PowerShell с ботом должен быть запущен постоянно. Закрыли окно или выключили
компьютер — напоминания в это время отправить некому.

## Запуск

1. Скопируйте `.env.example` в `.env`.
2. В `.env` вставьте токен, полученный у @BotFather.
3. Откройте PowerShell в этой папке и выполните:

   ```powershell
   ..\Scripts\python.exe bot.py
   ```

4. Откройте своего бота и отправьте `/start`.

Пока окно PowerShell открыто, бот работает. Данные лежат в `data.sqlite3`, а
готовые акты — в папке `acts`.
